# Hoopoe Design

The central repository for Hoopoe Design's brand identity, assets, guidelines, and working references.

This repository will grow over time to include:
- Brand identity and logo assets
- Brand guidelines, colour, and typography references
- Tone of voice and communication standards
- Hudhud mascot assets and illustration style references
- Marketing and application examples

## Logo assets

The current logo set is stored in `assets/Logo/`:

- `Primary Logo/` contains the primary logo and its variations.
- `Secondary Logo/` contains the secondary logo and its variations.
- `Favicon/` contains favicon artwork and its variations.

All supplied SVG files are kept as individual vector assets.
